# 📚 Papelería El Retiro

Sitio web desarrollado para **Papelería El Retiro**, una papelería local cuyo objetivo es ofrecer una presencia digital moderna, intuitiva y accesible para que sus clientes puedan conocer sus productos, servicios e información de contacto de forma rápida y sencilla.

## 🌟 Descripción

Este proyecto consiste en el desarrollo de una página web corporativa diseñada para mejorar la visibilidad online de la papelería y facilitar el acceso a la información más importante del negocio.

La web presenta un diseño limpio, responsive y fácil de navegar, adaptándose correctamente a dispositivos móviles, tablets y ordenadores.

## ✨ Características

- 🏪 Presentación del negocio.
- 🛍️ Información sobre los productos disponibles.
- 📍 Ubicación y datos de contacto.
- 📱 Diseño responsive para cualquier dispositivo.
- ⚡ Navegación rápida e intuitiva.
- 🎨 Interfaz moderna y agradable para el usuario.
- 📧 Acceso sencillo a los medios de contacto.
